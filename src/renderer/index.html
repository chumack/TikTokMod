Как это работает

        

          

            Мобильные приложения TikTok определяют страну по SIM-карте. Модуль
            UnleashedTikTok подменяет ответы TelephonyManager
            (страна BY, оператор 25704), и официальный APK
            ведёт себя как белорусский телефон.
          

          

            На десктопе этих вызовов нет, поэтому то же самое делается на уровне сети:
            приложение само указывает регион, оператора, часовой пояс и идентификатор
            устройства в мобильном API TikTok. Запрос уходит POST на
            /aweme/v1/multi/aweme/detail/ — тот же эндпоинт, который
            использует yt-dlp, и он принимает пустой X-Argus, то есть
            подпись запросов не нужна.
          

          

            Подмена региона меняет только то, что приложение сообщает о себе. Самый
            частый источник «TikTok показывает только старые видео» — реальный IP:
            сервер применяет ограничения по адресу подключения. Прокси в выбранной
            стране остаётся обязательной частью схемы.
